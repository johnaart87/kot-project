# Kot project: публикация на GitHub Pages и установка

Готовая к публикации программа лежит в папке `site`. Её содержимое нужно один раз выложить на GitHub Pages. После этого программа ставится на компьютер, Samsung и iPad.

## 1. Аккаунт GitHub (один раз)
1. Зарегистрируйтесь на https://github.com/signup. Бесплатного аккаунта достаточно.
2. Запомните имя пользователя: из него получится адрес программы.

## 2. Репозиторий (один раз)
1. Нажмите «+» → **New repository**.
2. **Repository name:** `kot-project`.
3. Выберите **Public**. На бесплатном тарифе Pages работает только с публичными репозиториями. Виден будет код программы, а ваши проекты остаются только на ваших устройствах.
4. Нажмите **Create repository**.

## 3. Загрузка файлов
1. На странице репозитория нажмите ссылку **uploading an existing file**.
2. Откройте в Проводнике папку `C:\Users\kot_a\Kot project\site`.
3. Выделите **всё её содержимое** (`index.html`, `manifest.webmanifest`, `sw.js`, `.nojekyll`, папку `icons`) и перетащите в окно браузера.
4. Нажмите **Commit changes**.

## 4. Включение Pages
1. В репозитории откройте **Settings → Pages**.
2. **Source:** *Deploy from a branch*. **Branch:** `main`, папка `/ (root)` → **Save**.
3. Через 1–2 минуты программа откроется по адресу `https://ИМЯ.github.io/kot-project/`.

## 5. Установка
- **Компьютер (Edge или Chrome).** Откройте адрес. Нажмите значок «Установить» в адресной строке или меню ⋯ → «Приложения» → «Установить Kot project».
- **Samsung (Chrome или Samsung Internet).** Меню ⋮ → «Установить приложение» или «Добавить на главный экран».
- **iPad (Safari).** «Поделиться» → «На экран „Домой“» → «Добавить».

После первого запуска программа работает без интернета. Исключение — фото и сложные фразы: для них нужен Claude, а значит интернет.

## Обновление программы
1. Запустите сборку:
   `powershell -ExecutionPolicy Bypass -File build.ps1`
2. Снова загрузите содержимое `site` в репозиторий (шаг 3). GitHub заменит старые файлы.
3. Установленные копии получат новую версию при следующем запуске с интернетом.

## Фото и сложные фразы в установленной программе
В чате нажмите шестерёнку и вставьте свой ключ Claude API (console.anthropic.com → API Keys).
- Ключ хранится только на этом устройстве.
- Оплата идёт по факту с вашего счёта Anthropic. Разбор одного фото обычно стоит несколько центов.
