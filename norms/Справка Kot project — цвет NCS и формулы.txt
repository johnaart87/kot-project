Справка Kot project «Цвет по системе NCS: как строится обозначение, формулы, подбор» (2026). NCS (Natural Colour System, «естественная система цвета») разработана Скандинавским институтом цвета (Швеция), национальный стандарт Швеции SS 19100/19102. Система описывает цвет так, как его видит человек, — через сходство с шестью элементарными цветами. Пересказ своими словами; точные образцы — по сертифицированному атласу или веерам NCS.

1 Элементарные цвета
1.1 В NCS шесть элементарных цветов: белый (W), чёрный (S, от шведского svart), жёлтый (Y), красный (R), синий (B), зелёный (G).
1.2 Любой цвет описывается долями сходства с ними: насколько он чёрный, насколько хроматичный (насыщенный) и каким тоном (между какими элементарными хроматическими цветами он лежит).

2 Как читать обозначение NCS
2.1 Пример: NCS S 2030-Y90R.
2.2 «S» — стандартный образец второго издания атласа (Standard). Буква не входит в расчёт.
2.3 Первые две цифры — чернота s, %: здесь s = 20.
2.4 Следующие две цифры — хроматичность c, %: здесь c = 30. Вместе «2030» называют нюансом цвета.
2.5 После дефиса — тон φ: «Y90R» — жёлтый с 90 % красного, то есть почти красный (оранжево-красный оттенок). Тон всегда записывается от предыдущего элементарного цвета по кругу: Y…R, R…B, B…G, G…Y.
2.6 Нейтральные (ахроматические) цвета: тона нет, пишется «N»: NCS S 0500-N — самый светлый белый образец (чернота 5 %), S 9000-N — почти чёрный. Пример светло-серого: S 2000-N.
2.7 Почти нейтральные цвета с оттенком: S 1002-Y — белый с хроматичностью 2 % жёлтого тона («тёплый белый»), S 1502-B — холодный светло-серый.
2.8 Чистый элементарный тон пишется одной буквой: S 1080-Y — насыщенный жёлтый без примеси красного или зелёного.

3 Формулы NCS
3.1 Сумма составляющих: s + w + c = 100, где s — чернота, w — белизна, c — хроматичность, все в процентах.
3.2 Белизна: w = 100 − s − c. Для S 2030-Y90R: w = 100 − 20 − 30 = 50 %.
3.3 Тон делит хроматичность между двумя соседними элементарными цветами. Для тона Y90R доля красного r = 90 %, доля жёлтого y = 10 % хроматической части.
3.4 Состав цвета по элементарным цветам: жёлтый = c × y / 100, красный = c × r / 100. Для S 2030-Y90R: жёлтый = 30 × 10 / 100 = 3 %, красный = 30 × 90 / 100 = 27 %, чёрный 20 %, белый 50 %; сумма 3 + 27 + 20 + 50 = 100 %.
3.5 Тоновый круг: четыре элементарных хроматических цвета стоят через 90°, между соседними по 100 ступеней (1 ступень = 0,9°). Угол тона (от жёлтого по часовой стрелке): Y = 0°, R = 90°, B = 180°, G = 270°; угол = угол начального цвета + число × 0,9°. Примеры: Y90R = 0° + 90 × 0,9° = 81°, R50B = 90° + 45° = 135°, B20G = 180° + 18° = 198°, G70Y = 270° + 63° = 333°.
3.6 Противоположный тон на круге — прибавить 180°: для Y90R (81°) получается 261° = B + 81° = B90G (сине-зелёный, почти зелёный). Противоположный тон в NCS — тон с наименьшим сходством, он не обязательно совпадает с «дополнительным» цветом оптики.
3.7 Треугольник NCS: для одного тона все цвета лежат в треугольнике с вершинами W (белый), S (чёрный) и C (максимальная хроматичность этого тона). Линии в треугольнике:
— одинаковая чернота (s = const) — цвета одной «глубины», линия параллельна стороне W–C;
— одинаковая хроматичность (c = const) — одинаковая насыщенность, линия параллельна стороне W–S;
— одинаковая белизна (w = const) — линия параллельна стороне S–C.
3.8 Одинаковый нюанс (например, 2030) в разных тонах воспринимается как одинаково «тяжёлый» и насыщенный — на этом строится гармония по нюансу.

4 Светлота, отражение света (LRV) и контраст
4.1 LRV (коэффициент отражения света, %) — какую долю света отражает поверхность: белая краска 80–90 %, светло-серая 50–70 %, средние тона 20–40 %, тёмные до 10 %. LRV указывается в паспорте цвета производителя.
4.2 По цвету на экране (sRGB) LRV оценивают так: каждый канал R, G, B (0…255) делят на 255; линейное значение: если значение ≤ 0,04045, то V/12,92, иначе ((V + 0,055) / 1,055)^2,4. Затем яркость Y = 0,2126·R + 0,7152·G + 0,0722·B; LRV ≈ 100 · Y. Это оценка: экран и краска не совпадают.
4.3 Контраст по яркости для маломобильных людей: в мировой практике (британский стандарт BS 8300) разница LRV двух поверхностей — не менее 30 пунктов (например, дверь и стена, пол и стена, поручень и фон).
4.4 Контраст текста (WCAG): K = (L1 + 0,05) / (L2 + 0,05), где L1 и L2 — яркости Y более светлого и более тёмного цветов по п. 4.2. Хорошо читается при K ≥ 4,5.
4.5 Разница цветов ΔE (CIELAB): ΔE = √(ΔL² + Δa² + Δb²). ΔE < 1 — разницы почти не видно, 1–2 — видна при сравнении вплотную, больше 3–5 — заметна сразу. Колеровку краски проверяют по ΔE.
4.6 Точной формулы перевода NCS в RGB нет: официальный перевод идёт через измерение (CIELAB) каждого образца. Программы и веера дают приближённые значения; на экране цвет всегда проверяйте по физическому образцу при нужном свете.

5 Практика подбора цвета по NCS
5.1 Светлые фоны для стен: чернота 05–10, хроматичность 02–10 (S 0502-Y, S 0804-Y30R, S 1002-G50Y). Потолок обычно светлее стен на 5–10 по черноте.
5.2 Чтобы цвет «не кричал» на большой стене, берите хроматичность не выше 10–20; насыщенные (c ≥ 40) — для акцентов и мелких поверхностей.
5.3 Тёплый оттенок — тона от Y до R (Y10R…Y90R); холодный — B и соседние (R80B…B50G). Для комнат на север — тёплые тона, на юг — можно холодные и нейтральные.
5.4 Тон-в-тон: один тон (например, Y20R), разные нюансы — 0505, 1010, 2020, 3030; спокойная монохромная гамма.
5.5 Гармония по нюансу: одинаковый нюанс (например, 2010), разные тона — Y30R, G30Y, B — сочетаются ровно, без контраста по насыщенности.
5.6 Контраст для акцента: тот же тон, чернота больше на 30–50 (S 1010-Y30R и S 5010-Y30R) или противоположный тон с той же хроматичностью.
5.7 Свет меняет цвет: при светильниках 2700–3000 K цвета теплеют, при 4000 K и дневном свете — холодеют; одинаковые на образце краска и ткань при другом свете могут разойтись (метамерия). Утверждайте цвет на месте при своём освещении.
5.8 Блеск и фактура в обозначение NCS не входят: один и тот же NCS на матовой и глянцевой краске выглядит по-разному (глянец кажется темнее и насыщеннее).
